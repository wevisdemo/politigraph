คุณสามารถใช้งาน 🗄️ Politigraph เพื่อเข้าถึงข้อมูลที่ต้องการได้ 3 วิธี

## 1. GraphQL API

```text wrap
💻 — Query → 🗄️ — ข้อมูล → 💻
```

เหมาะสำหรับผู้ที่ต้องการนำข้อมูล Politigraph ไปใช้ในเว็บไซต์ แอปพลิเคชัน หรือกระบวนการทำงานอื่นๆ โดยเขียน GraphQL Query และส่งคำขอไปยังระบบเพื่อดึงข้อมูลที่ต้องการ

[ดูวิธีใช้งาน](/usage/api)

## 2. 🛝 GraphQL Playground

```text wrap
👦 — สร้าง Query → 🛝 — Query → 🗄️ — ข้อมูล → 🛝 — แสดงผล → 👦
```

เหมาะสำหรับผู้ที่ต้องการดึงข้อมูลจาก Politigraph ออกมาใช้ โดยมี User Interface ช่วยในการเขียน GraphQL Query ดูผลลัพธ์ และดาวน์โหลดข้อมูลไปใช้ได้ทันทีโดยไม่ต้องเขียนโค้ดเพิ่มเติม

[ดูวิธีใช้งาน](/usage/graphql-playground)

## 3. ใช้งานร่วมกับ AI 🤖

เหมาะสำหรับผู้ที่ต้องการดึงข้อมูลจาก Politigraph ออกมาใช้ เพื่อตอบคำถามที่อยากทราบหรือนำไปวิเคราะห์ต่อ โดยไม่ต้องเขียน GraphQL Query ด้วยตัวเอง โดยสามารถใช้ AI ช่วยได้ 2 ช่องทาง ผ่าน llms.txt และ MCP

### 3.1 ให้ AI ช่วยเขียน GraphQL Query ด้วย llms.txt

```text wrap
👦 — ถาม (Prompt) → 🤖 — ช่วยเขียน Query ให้ → 👦 — สร้าง Query → 🛝 — Query → 🗄️ — ข้อมูล → 🛝 — แสดงผล → 👦
```

เหมาะสำหรับผู้ใช้งาน AI Chat บนเว็บซึ่งอาจมีข้อจำกัดในการเรียกใช้ข้อมูล ผู้ใช้ต้องนำ Query ที่ AI ช่วยเขียนไปใช้ต่อใน GraphQL Playground เหมือนข้อที่ 2

[ดูวิธีใช้งาน](/usage/ai#ให้-ai-ช่วยเขียน-graphql-query-ด้วย-llmstxt)

### 3.2 ให้ AI ดึงข้อมูลโดยตรงผ่าน MCP

```text wrap
👦 — ถาม (Prompt) → 🤖 — Query → 🗄️ — วิเคราะห์ข้อมูล → 🤖 — ตอบ → 👦
```

เหมาะสำหรับผู้ใช้งาน AI Agent บนเครื่องที่รองรับการเชื่อมต่อกับระบบภายนอกผ่าน Model Context Protocol (MCP) AI Agent จะสามารถนำผลลัพธ์มาตอบผู้ใช้งานได้เลยทันที

[ดูวิธีใช้งาน](/usage/ai#ให้-ai-ดึงข้อมูลโดยตรงผ่าน-mcp)
