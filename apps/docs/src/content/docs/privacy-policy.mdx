_มีผลใช้บังคับตั้งแต่วันที่ 24 กันยายน 2569_

นโยบายนี้ใช้บังคับกับ "ข้อมูลส่วนบุคคล" ที่ถูกประมวลผลผ่าน Politigraph ซึ่งดำเนินการโดย WeVis ("ผู้ควบคุมข้อมูลส่วนบุคคล") และบุคคลภายนอกที่ประมวลผลข้อมูลส่วนบุคคลแทนหรือในนามของ WeVis ("ผู้ประมวลผลข้อมูลส่วนบุคคล") ภายใต้บริการต่าง ๆ ได้แก่ เว็บไซต์และเอกสารประกอบที่ [politigraph.wevis.info](https://politigraph.wevis.info) พื้นที่สำรวจข้อมูล GraphQL API พร้อม GraphQL Playground (`/graphql`) และ MCP Server (`/mcp`) (รวมเรียกว่า "บริการ")

Politigraph เป็นโครงการภาคประชาสังคมที่เปิดให้ใช้งานข้อมูลการเมืองไทยได้โดยไม่ต้องสมัครสมาชิก เราจึงออกแบบบริการให้เก็บข้อมูลเกี่ยวกับผู้ใช้งานให้น้อยที่สุดเท่าที่จำเป็น

## ประเภทของข้อมูลส่วนบุคคลที่ถูกรวบรวม

### ผู้ใช้งาน GraphQL API และ MCP Server

บริการเหล่านี้ใช้งานได้โดยไม่ต้องยืนยันตัวตน ทุกครั้งที่มีการเรียกใช้งาน เราบันทึกข้อมูลการใช้งานดังนี้

- ส่วนของ Schema ที่ถูกเรียกใช้ในแต่ละ Query ในรูปแบบ `Type.field` ชื่อ Operation และระยะเวลาในการประมวลผล
- ชื่อแอปพลิเคชันที่เรียกใช้งาน จาก Origin ของเบราว์เซอร์ หรือจาก Header `apollographql-client-name` ที่ผู้ใช้งานระบุเอง
- ชื่อและเวอร์ชันของโปรแกรม MCP Client และชื่อเครื่องมือ (Tool) ที่ถูกเรียกใช้
- ข้อมูลการเข้าถึงเว็บไซต์ ได้แก่ Path ที่เรียกใช้ (ไม่รวม Query String) สถานะการตอบกลับ ระยะเวลาตอบสนอง User Agent และส่วนต้นของหมายเลข IP (Network Prefix) เท่านั้น
- ค่าแฮช (Hash) ของหมายเลข IP และ User Agent เพื่อนับจำนวนผู้ใช้งานที่ไม่ซ้ำกัน โดยค่านี้ถูกสร้างด้วยค่าสุ่มที่เปลี่ยนใหม่ทุกวันและไม่ถูกบันทึกไว้ จึงไม่สามารถย้อนกลับไปหาหมายเลข IP หรือเชื่อมโยงข้ามวันได้

เราไม่บันทึกเนื้อหาของ Query ตัวแปร (Variables) ผลลัพธ์ที่ตอบกลับ หรือหมายเลข IP แบบเต็ม

### ผู้เข้าชมเว็บไซต์

เราใช้ [Plausible Analytics](https://plausible.io) เพื่อวัดสถิติการเข้าชมเว็บไซต์ โดยไม่ใช้คุกกี้และไม่เก็บหมายเลข IP ข้อมูลที่ถูกบันทึก ได้แก่

- หน้าเว็บที่เข้าชม และเว็บไซต์ต้นทางที่ส่งท่านมา (Referrer)
- ประเภทเบราว์เซอร์ ระบบปฏิบัติการ และประเภทอุปกรณ์
- ประเทศและภูมิภาคโดยประมาณ ซึ่งคำนวณจากหมายเลข IP ขณะรับข้อมูลโดยไม่จัดเก็บหมายเลข IP นั้น

### ผู้ที่ติดต่อเรา

ข้อมูลที่ท่านส่งให้เราโดยสมัครใจ เช่น ชื่อ อีเมล และเนื้อหาของข้อความ เมื่อท่านติดต่อผ่านอีเมลหรือแจ้งปัญหาผ่าน GitHub

## ข้อมูลส่วนบุคคลของบุคคลในชุดข้อมูล

ชุดข้อมูลของ Politigraph ประกอบด้วยข้อมูลเกี่ยวกับนักการเมืองและบุคคลที่ดำรงตำแหน่งทางการเมือง เช่น ชื่อ รูปภาพ วันเกิด ประวัติการศึกษาและการทำงาน การดำรงตำแหน่ง สังกัดพรรคการเมือง และการลงมติในรัฐสภา ข้อมูลเหล่านี้รวบรวมจากแหล่งข้อมูลที่เปิดเผยต่อสาธารณะ เช่น เอกสารของรัฐสภาและหน่วยงานราชการ เพื่อประโยชน์สาธารณะในการส่งเสริมความโปร่งใสและการตรวจสอบการทำงานของผู้แทนประชาชน

เราเปิดเผยเฉพาะข้อมูลที่ผ่านการตรวจสอบแล้วเท่านั้น หากท่านเป็นบุคคลในชุดข้อมูลและพบว่าข้อมูลไม่ถูกต้องหรือไม่ครบถ้วน สามารถแจ้งขอแก้ไขได้ตามหัวข้อ [ติดต่อสอบถามหรือใช้สิทธิ](#ติดต่อสอบถามหรือใช้สิทธิ)

## การใช้และประมวลข้อมูลส่วนบุคคล

เราประมวลผลข้อมูลส่วนบุคคลตามวัตถุประสงค์ดังนี้

- เพื่อให้บริการเว็บไซต์ API และ MCP Server อย่างมีเสถียรภาพ รวมถึงตรวจหาและแก้ไขข้อผิดพลาด
- เพื่อป้องกันการใช้งานที่ผิดปกติหรือการโจมตีระบบ และรักษาความปลอดภัยของบริการ
- เพื่อวิเคราะห์ภาพรวมการใช้งาน เช่น ส่วนของข้อมูลที่ได้รับความนิยม เพื่อพัฒนาบริการและวางแผนการเปลี่ยนแปลง Schema โดยไม่กระทบผู้ใช้งาน
- เพื่อตอบกลับและดำเนินการตามคำขอของผู้ที่ติดต่อเรา
- เพื่อเปิดเผย นำเสนอข้อมูล หรือจัดทำรายงานสรุปภาพรวมทางสถิติโดยไม่ระบุตัวตน

เราไม่ใช้ข้อมูลส่วนบุคคลเพื่อการโฆษณา ไม่ขาย และไม่แลกเปลี่ยนข้อมูลส่วนบุคคลกับบุคคลภายนอก นอกจากนี้ เราอาจเปิดเผยข้อมูลเมื่อจำเป็นเพื่อปฏิบัติตามกฎหมาย หรือตามคำขอของหน่วยงานของรัฐหรือผู้มีอำนาจ

## คุกกี้ (Cookies)

เว็บไซต์และบริการของ Politigraph ไม่ใช้คุกกี้กับผู้เข้าชมและผู้ใช้งาน API และไม่ใช้คุกกี้เพื่อติดตามหรือโฆษณา ส่วนการตั้งค่าการแสดงผลของเว็บไซต์ เช่น ธีมสีสว่างหรือมืด จะถูกบันทึกไว้บนอุปกรณ์ของท่านและไม่ถูกส่งมายังเรา

## การจัดเก็บและรักษาความปลอดภัยของข้อมูลส่วนบุคคล

เราเก็บรักษาข้อมูลส่วนบุคคลเท่าที่จำเป็นตามวัตถุประสงค์ ดังนี้

- ข้อมูลการใช้งาน API และ MCP Server เก็บไว้ไม่เกิน 1 ปี และข้อมูลการเข้าถึงเว็บไซต์เก็บไว้ไม่เกิน 30 วัน
- ข้อมูลสำรอง (Backup) ของระบบเก็บไว้ไม่เกิน 30 วัน
- ข้อมูลสถิติที่ไม่สามารถระบุตัวบุคคลได้ อาจถูกเก็บไว้ต่อไปเพื่อใช้ในการวิเคราะห์

เรามีมาตรการปกป้องข้อมูลส่วนบุคคล โดยจำกัดสิทธิ์การเข้าถึงให้เฉพาะทีมงานที่มีหน้าที่ดูแลระบบ เข้ารหัสการรับส่งข้อมูลทั้งหมดผ่าน HTTPS ตัดทอนหมายเลข IP และแทนที่อีเมลในบันทึกของระบบก่อนจัดเก็บ ตลอดจนแยกระบบฐานข้อมูลออกจาก Server ที่ให้บริการ

## การส่งหรือโอนข้อมูลส่วนบุคคลไปยังต่างประเทศ

Server ที่ให้บริการและจัดเก็บข้อมูลของ Politigraph ตั้งอยู่ในประเทศไทย อย่างไรก็ตาม ในบางกรณีข้อมูลส่วนบุคคลของท่านอาจถูกส่งหรือโอนไปยังต่างประเทศเพื่อดำเนินการตามวัตถุประสงค์ในการให้บริการ ได้แก่ การรับส่งข้อมูลผ่านเครือข่ายของ Cloudflare ซึ่งมี Server กระจายอยู่ทั่วโลก และการจัดเก็บข้อมูลสำรองบนระบบคลาวด์ (Cloud) ของ Amazon Web Services ในประเทศสิงคโปร์

## ผู้ประมวลผลข้อมูลส่วนบุคคล

ในบางกรณี เราได้มอบหมายบุคคลที่สาม (ผู้ประมวลผลข้อมูลส่วนบุคคล) ให้ทำการประมวลผลข้อมูลส่วนบุคคล ซึ่งท่านสามารถศึกษานโยบายคุ้มครองข้อมูลส่วนบุคคลของผู้ประมวลผลข้อมูลส่วนบุคคลต่าง ๆ เพิ่มเติมได้ ดังนี้

- [Nimblo](https://nimblo.cloud) ผู้ให้บริการ Server
- [Cloudflare](https://www.cloudflare.com/privacypolicy)
- [Amazon Web Services](https://aws.amazon.com/privacy)
- [Plausible Analytics](https://plausible.io/data-policy) ติดตั้งและดูแลโดย Punch Up

## สิทธิของผู้ใช้

พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ได้กำหนดสิทธิของเจ้าของข้อมูลส่วนบุคคลไว้หลายประการ ได้แก่

- **สิทธิในการขอเข้าถึงข้อมูลส่วนบุคคล** ท่านมีสิทธิขอเข้าถึง รับสำเนา และขอให้เปิดเผยที่มาของข้อมูลส่วนบุคคลที่เราเก็บรวบรวมไว้ เว้นแต่กรณีที่เรามีสิทธิปฏิเสธคำขอด้วยเหตุตามกฎหมายหรือคำสั่งศาล หรือกรณีที่การใช้สิทธิของท่านอาจก่อให้เกิดความเสียหายต่อสิทธิและเสรีภาพของบุคคลอื่น
- **สิทธิในการขอแก้ไขข้อมูลส่วนบุคคล** หากท่านพบว่าข้อมูลส่วนบุคคลของท่านไม่ถูกต้อง ไม่ครบถ้วน หรือไม่เป็นปัจจุบัน ท่านมีสิทธิขอให้แก้ไขเพื่อไม่ก่อให้เกิดความเข้าใจผิด
- **สิทธิในการลบหรือทำลายข้อมูลส่วนบุคคล** ท่านมีสิทธิขอให้เราลบหรือทำลายข้อมูลส่วนบุคคลของท่าน หรือทำให้ข้อมูลไม่สามารถระบุตัวบุคคลได้ ภายใต้เงื่อนไขตามที่กฎหมายกำหนด
- **สิทธิในการขอให้ระงับการใช้ข้อมูลส่วนบุคคล** ท่านมีสิทธิขอให้ระงับการใช้ข้อมูลส่วนบุคคลของท่านชั่วคราว เช่น ระหว่างที่เราตรวจสอบคำขอแก้ไขข้อมูลของท่าน
- **สิทธิในการคัดค้านการประมวลผลข้อมูลส่วนบุคคล** ท่านมีสิทธิคัดค้านการเก็บรวบรวม ใช้ หรือเปิดเผยข้อมูลส่วนบุคคลที่เกี่ยวกับท่าน เว้นแต่กรณีที่เรามีเหตุในการปฏิเสธคำขอโดยชอบด้วยกฎหมาย
- **สิทธิในการขอถอนความยินยอม** ในกรณีที่ท่านได้ให้ความยินยอมแก่เรา ท่านมีสิทธิถอนความยินยอมเมื่อใดก็ได้ เว้นแต่มีข้อจำกัดสิทธิโดยกฎหมาย
- **สิทธิในการขอรับ ส่ง หรือโอนข้อมูลส่วนบุคคล** ท่านมีสิทธิขอรับข้อมูลส่วนบุคคลของท่าน รวมถึงขอให้ส่งหรือโอนไปยังผู้ควบคุมข้อมูลส่วนบุคคลรายอื่น ภายใต้เงื่อนไขตามที่กฎหมายกำหนด

เนื่องจากข้อมูลการใช้งานเว็บไซต์ API และ MCP Server ส่วนใหญ่ไม่สามารถระบุตัวบุคคลได้ ในบางกรณีเราอาจไม่สามารถค้นหาข้อมูลที่เกี่ยวข้องกับท่านเพื่อดำเนินการตามคำขอได้

## การปรับปรุงแก้ไขนโยบายการคุ้มครองข้อมูลส่วนบุคคล

เราอาจพิจารณาปรับปรุง แก้ไข หรือเปลี่ยนแปลงนโยบายนี้ตามที่เห็นสมควร โดยจะแจ้งวันที่แก้ไขล่าสุดไว้ที่ส่วนต้นของหน้านี้ การใช้บริการของ Politigraph ภายหลังการบังคับใช้นโยบายใหม่ ถือเป็นการรับทราบนโยบายฉบับใหม่แล้ว หากท่านไม่เห็นด้วยกับรายละเอียดในนโยบายฉบับนี้ โปรดหยุดการใช้บริการและติดต่อเราเพื่อชี้แจงข้อเท็จจริง

## ติดต่อสอบถามหรือใช้สิทธิ

หากท่านมีข้อสงสัย ข้อเสนอแนะ หรือข้อกังวลเกี่ยวกับการเก็บรวบรวม ใช้ และเปิดเผยข้อมูลส่วนบุคคล หรือเกี่ยวกับนโยบายนี้ หรือต้องการใช้สิทธิตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล กรุณาติดต่อ [team@wevis.info](mailto:team@wevis.info)
