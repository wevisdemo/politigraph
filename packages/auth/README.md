## Tech Stack

- Better Auth
- Drizzle + Bun SQL
- Postgres

## Structure

- `src/auth.ts` Better Auth server instance (`@politigraph/auth/auth`)
- `src/client.ts` browser client exports for the admin app (`@politigraph/auth/client`)
- `src/db.ts` Drizzle client shared by Better Auth and the API (`@politigraph/auth/db`)
- `src/schema/` Drizzle tables (`@politigraph/auth/schema/<name>`): `auth.ts` is generated by `better-auth generate`, every other file is hand-written
- `scripts/` `migrate` and `seed` entry points
- `drizzle/` generated SQL migrations

## Scripts

- `generate` generate migration file from current better-auth plugins
- `migrate` migrate Postgres database to match generated migration file
- `seed` create the local admin user and a test API key

## Audit Log

`src/schema/audit.ts` defines `audit_logs`, one row per GraphQL mutation made with a session or API key, written by the API's `audit-log` plugin: who (`user_id`, `via`, and `credential_id`: the session or API key id, from the JWT `sid` claim), what (`changes`, each root field's arguments by name), where (`node_ids`, every node id in the arguments and response) and when (`created_at`).

## Environment Variables

Managed by `@politigraph/config`. See `.env.example` at the project root for the full list.
